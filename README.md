# FindAJob

A backend application that connects job seekers with companies, providing a platform for users to find job opportunities and for companies to manage job listings.

## Features

- User registration and authentication
- JWT-based authentication
- Refresh token support
- Secure password hashing with BCrypt
- Role-based authorization
- Company management
- Job management
- Job applications
- Notifications
- PostgreSQL database integration
- Global exception handling
- Swagger/OpenAPI API documentation
- Rate limiting for authentication services

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA / Hibernate
- PostgreSQL
- Maven
- Swagger / OpenAPI
- Rate Limiting

## Database Setup

Create a PostgreSQL database:

```sql
CREATE DATABASE FindAJob;
```

Configure your database credentials in `application.properties`:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/FindAJob
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD

spring.jpa.hibernate.ddl-auto=update
```

## Installation

Clone the repository:

```bash
git clone https://github.com/karma7070/FindAJob.git
```

Navigate to the project:

```bash
cd FindAJob
```

Build the project:

```bash
mvn clean install
```

Run the application:

```bash
mvn spring-boot:run
```

The application runs on:

```text
http://localhost:8080
```

## Authentication

FindAJob uses JWT-based authentication with refresh token support.

### Authentication Flow

```text
Register
   ↓
Login
   ↓
Receive Access Token
   ↓
Send Token With Request
   ↓
JWT Authentication
   ↓
Access Protected Resources
```

Authenticated requests should include:

```http
Authorization: Bearer YOUR_JWT_TOKEN
```

## Core Modules

### Users

Handles user registration, authentication, and user-related functionality.

### Companies

Handles company-related functionality and management.

### Jobs

Handles job listings and job-related operations.

### Job Applications

Handles applications submitted by users for available jobs.

### Notifications

Handles notifications generated by application events.

### Refresh Tokens

Provides refresh-token functionality for maintaining authenticated sessions.

### Security

Handles authentication, authorization, JWT processing, rate limiting, and security configuration.

## API

The application exposes RESTful API endpoints for:

- User authentication
- Company management
- Job management
- Job applications
- Notifications
- Token management

API endpoints are protected according to the user's authentication status and role.

## API Documentation

The project includes Swagger/OpenAPI documentation for the REST API.

Swagger provides an interactive interface for viewing and testing available API endpoints.

## Rate Limiting

Rate limiting is implemented on the company login service and registered user login service to help prevent excessive authentication requests and reduce the risk of abuse.

## Security

The application uses:

- Spring Security
- JWT
- BCrypt Password Encoding
- Refresh Tokens
- Role-Based Authorization
- Rate Limiting

Sensitive credentials and passwords should not be committed to the repository.
